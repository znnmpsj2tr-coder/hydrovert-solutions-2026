# Hydrovert Solutions — V3 de démonstration

Cette copie est indépendante du site actuellement en ligne. Aucun changement dans ce dossier ne modifie `hydrovert-solutions-2026.vercel.app`.

## Pour la voir sur votre Mac

1. Ouvrez ce dossier dans VS Code.
2. Ouvrez le terminal intégré.
3. Lancez `npm run dev`.
4. Ouvrez l’adresse indiquée, généralement `http://localhost:3000`.

## Ce qui a été ajouté dans cette version

- Une section premium expliquant le parcours complet du client.
- Une mise en avant de l’étude de terrain et de la mesure de surface.
- Un aperçu visuel du futur suivi de dossier.
- Des micro-interactions sur les cartes et les boutons.
- Un message commercial plus clair : Hydrovert accompagne le client, mais ne promet pas de devis ou de résultats automatiques.

## À configurer avant une vraie mise en ligne

- Votre adresse e-mail de réception.
- Un stockage sécurisé pour les photos.
- La confirmation e-mail au client.
- Vos coordonnées et votre zone d’intervention.
- Vos premières réalisations et avis clients authentiques.

Les éléments “suivi de dossier” sont volontairement présentés comme un aperçu : ils ne simulent pas une fonctionnalité qui n’est pas encore reliée à un e-mail ou à un stockage.
