# Hydrovert Solutions — V4 Premium

Cette V4 est une prévisualisation locale séparée du site actuellement en ligne.

## Principales évolutions

- nouvelle page d’accueil avec hero cinématique et photographie documentaire ;
- animations d’entrée, parallaxe, bandeau cinétique et progression au défilement ;
- page **Démonstration** avec une vidéo d’application réelle ;
- navigation enrichie et responsive sur téléphone, tablette et ordinateur ;
- photographies et vidéo issues de sources du domaine public ;
- page de crédits médias pour distinguer clairement les illustrations des réalisations Hydrovert ;
- conservation du guide d’irrigation, de la mesure de terrain et de l’assistant FAQ.

## Prévisualiser

```bash
npm install
npm run dev
```

Puis ouvrir `http://localhost:3000`.

## Médias

- Photographies : U.S. Army Corps of Engineers / Todd Plain, domaine public, via Wikimedia Commons.
- Vidéo : U.S. Army Corps of Engineers / Melanie Oubre, domaine public, via DVIDS.

Les médias illustrent la technique et ne sont pas présentés comme des chantiers réalisés par Hydrovert Solutions.
